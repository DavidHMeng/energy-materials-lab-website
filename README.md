# Placeholder Energy Materials Lab website

A bilingual Jekyll research-group site based on Greene Lab Website Template v1.4.0,
with DOI-driven publications and Pages CMS content editing.

Production domain: <https://jliang.eitech.edu.cn/>. The source is root-path compatible
(`baseurl: ""`). DNS and GitHub Pages cutover status is tracked in
`DOMAIN_MIGRATION.md`; production deployment is intentionally blocked until GitHub
Pages reports the approved custom domain.

See `BUILD_SPEC.md` for setup and verification, `CONTENT_SCHEMA.md` for editorial data,
`IMPLEMENTATION_AUDIT.md` and `PROJECT_STATUS.md` for the current evidence boundary,
`PAGES_CMS_GUIDE.md` for the verified editorial workflow, and `AGENTS.md` for frozen
information-architecture rules.
